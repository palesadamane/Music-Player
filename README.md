## Overview

MusicPlayer is a desktop music application built with Python that allows users to play audio files, manage playlists, and interact with a graphical user interface.

This project was created to practice building a desktop application, working with audio playback, file handling, and GUI development in Python.

## Features

- Audio playback
- Play, pause, and control music
- Playlist management
- Favorites functionality
- Custom graphical user interface
- Album artwork and music information display

## Technologies Used

- Python
- Tkinter
- Pygame
- Mutagen

## Project Structure

The project is organized into different files with separate responsibilities:

- `player.py` - Handles the graphical user interface (GUI) and user interaction
- `engine.py` - Handles the core application logic and music player functionality
- `music/` - Contains audio files used by the application
